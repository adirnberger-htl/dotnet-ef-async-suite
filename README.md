# .NET 8 Entity Framework Core, Clean Architecture & Async Suite

A comprehensive collection of .NET 8 / C# projects showcasing:
- **Entity Framework Core**: Code-First migrations, relational modeling, integration testing.
- **Clean Architecture**: Domain modeling, service layers, and decoupled repository patterns (`measurements_clean`, `measurements_entity-framework`).
- **Asynchronous Programming**: Custom async/await scrapers, HTTP response analysis (`ex_async_url-response-img-count-starter`).
- **LINQ & Custom Query Engines**: Custom `IEnumerable` extensions and generic collections (`vsCodeInDocker/deploy/shared/myQuery`).
- **Containerized Development**: Dev environments with VS Code in Docker.
